Added support for the `BIG` type to the `DIV` function and the `%` operator.
Added `MOD` and `REM` functions for remainders with the sign of the divisor and dividend, respectively.
Added the `FLOOR_DIV` function for division rounded toward negative infinity.
Changed the `/` and `%` operators and the `DIV`, `FLOOR_DIV`, `MOD`, and `REM` functions to reject integer zero divisors in API version 6.
