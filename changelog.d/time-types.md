Added the `INSTANT`, `TIME`, and `LOCAL_TIME` classes.

Added ISO 8601 string conversion methods to the time classes.

Added the `epochSeconds`, `epochMilliseconds`, and `epochNanoseconds` properties to `INSTANT` and `TIME`.
